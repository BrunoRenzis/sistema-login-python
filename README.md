# 🔐 Sistema de Login e Cadastro

Sistema de autenticação em Python com validação de senha forte e persistência de dados em JSON.

## 📋 Funcionalidades

- **Cadastro de usuários** com validação de senha
- **Login** com verificação de credenciais
- **Validação de senha forte**:
  - Mínimo 8 caracteres
  - Pelo menos 1 número
  - Pelo menos 1 letra maiúscula
- Verificação de usuários duplicados
- Dados salvos em arquivo JSON

## 🚀 Como usar
```bash
python login.py
```

## 📦 Dependências
```bash
pip install colorama
```

## 💡 Conceitos aplicados

- Manipulação de arquivos JSON
- Funções e modularização
- Validação de dados com list comprehension
- Tratamento de exceções (try/except)
- Estruturas de repetição e condicionais
